# 🏙️ Границы городов

Локальный каталог содержит Москву и Санкт-Петербург. Файлы являются архивными административными границами OSM, выгруженными в декабре 2016 года. Актуальность на текущую дату не подтверждена. Геометрия сохранена без упрощения координат; исходные свойства заменены компактными метаданными происхождения.

Источник: [missinglink/osm-boundaries](https://github.com/missinglink/osm-boundaries), дата снимка — [8 декабря 2016 года](https://github.com/missinglink/osm-boundaries/blob/master/last_modified.txt). Для каждого города ссылка на исходный файл и идентификатор отношения OSM сохранены в каталоге и GeoJSON.

## ➕ Добавление города

Добавьте полигональный файл в эту папку и запись в `catalog.json`. Поля: `id`, `name`, `label`, `aliases`, `file`, `snapshot`, `source_url`. Путь начинается с `boundaries/`, имя файла содержит латинские строчные буквы, цифры и дефисы, расширение — `.geojson`. Пример: `boundaries/tomsk.geojson`.

`label` должен показывать, какая граница выбрана и к какой дате относится снимок. Для чужих файлов сохраните их источник и условия использования. Не заменяйте административную границу приблизительно нарисованным контуром без явного пояснения.

Проверьте новый файл командой `python test_geometry.py -v` из корня репозитория, затем перезагрузите страницу карты. Поиск использует только этот локальный каталог и не обращается к сервисам геокодирования.

В отдельной пустой папке браузеров установка и первый запуск Chromium 136.0.7103.25 заняли **29,158 секунды**. Второй запуск — **0,089 секунды**, установщик за оба запуска вызван один раз. ## 💾 Экспорт GeoJSON — 3 октября 2026 года

Новый потребитель — GeoJSON с одной точкой организации и вложенным списком её отзывов. Этапы: необязательный фильтр подтверждённых → преобразование пропусков и дат → группировка по идентификатору за один проход → сборка FeatureCollection → существующая атомарная запись. Сложность O(N + R), где N — организации, R — отзывы. Повторных фильтраций всех R строк для каждой организации, GeoPandas, второго сбора, перепроецирования или округления координат нет. Экспорт является явным вызовом и не добавляется к каждому сбору автоматически.

Ограниченная проверка на сохранённых 663 реальных отзывах: все тексты, звёзды и исходные даты сохранены; 600 записей подтверждены, 63 остаются прежними. Фильтр экспортирует 600, сохраняя исходный счётчик 663 и статус `stalled`. Три построения словаря заняли 0,099 / 0,104 / 0,098 секунды; три атомарные записи с построением — 0,293 / 0,292 / 0,307 секунды. Медианы — **0,099** и **0,293 секунды**. Измерения выполнены с включённым `tracemalloc`: пик выделений Python **0,974 МиБ**, не RSS. Размер файла — **624 382 байта**. Холодный импорт и чтение исходного снимка в эти времена не входят. Новых сетевых запросов нет.

Пройдены **87 автономных проверок за 23,765 секунды**. Дополнительно проверены группировка двух организаций, пустая коллекция, пропущенные поля и геометрия, точные координаты, даты, оба режима подтверждения, работа без GeoPandas и сохранение прежнего файла при отказе сериализации. Исходные таблицы остаются без изменений.

## 🐍 Функции Python, таблицы и полный справочник — 3 октября 2026 года

Базовая версия сборщика — `9221045`. Сетевые этапы, паузы, лимиты и обработка частичных снимков сохраняются. Новый потребитель — две связанные таблицы для анализа и, по запросу, точки организаций. Геометрия и отзывы не сокращаются ради скорости. Функция вызывает существующий сценарий в отдельном процессе; дополнительный браузер и второй поиск не создаются. Готовый совместимый кэш по-прежнему позволяет не открывать браузер вообще.

Новые этапы: подготовка территории и выбор категорий → существующий сценарий → чтение манифеста и выбранных снимков → создание таблиц → фильтр подтверждённости → необязательный GeoDataFrame. Каждый снимок читается один раз, диагностика не повторяет массив отзывов, общей оценки из части звёзд не вычисляется. Старые неподтверждённые строки сохраняются с явными признаками происхождения. Строковые идентификаторы не переводятся в числа; даты разбираются в UTC с сохранением исходных строк.

На сохранённом реальном снимке 663 отзывов проведены три измерения загрузки: **0,076 / 0,069 / 0,068 секунды**, медиана **0,069 секунды**. Во всех проходах сохранены исходные тексты, звёзды и строки дат; 600 записей подтверждены, 63 остаются прежними, готовность частичного результата ложная. Пик выделений Python по `tracemalloc` — **3,44 МиБ**; это не RSS процесса. Создание пространственной таблицы одной организации заняло **0,007 секунды**. Чтение полного каталога 1609 настроек — **0,005 секунды**. Версии проверки: Python 3.11.7, Pandas 3.0.6, GeoPandas 1.2.0. Холодный импорт библиотек в эти времена не входит.

Справочник загружается один раз при разрешении выбранных категорий. Проверка всего каталога выполняется двумя групповыми проходами, а не повторным чтением JSON для каждой из 1609 записей. В интерфейсе строки вставляются через `DocumentFragment`, текст для фильтрации подготавливается один раз, фильтр сохраняет флажки. Проверены все 1609 строк в настоящем Chromium и смена фильтра с выбранной скрытой рубрикой. Ускорение основного сетевого сбора не заявляется.

Пройдены 84 автономные проверки за **21,835 секунды**. Отдельно проверена установка собранного wheel вне рабочей папки: импорт, локальный городской полигон, 1609 настроек, реальный вызов дочернего сценария по готовому поисковому кэшу и преобразование таблиц. Для этих проверок запросов к Яндексу не выполнялось; прежние сетевые измерения ниже используются для неизменённой ветви сбора. ## 🔄 Кэш, ресурсы и дальнейший объём

Кэш соответствует `schema_version = 1` и идентификатору организации. Готовность требует уникальных ключей, текста, даты, целой оценки 1–5 и отсутствия сокращений. Состояния ошибки и промежуточный `running` не считаются завершённым сбором. Возобновление открывает страницу заново и объединяет её содержимое с ранее сохранёнными текстами.

Сеть и ожидание новых карточек остаются основным ограничением. Для ориентира: N похожих карточек потребуют примерно N × время попытки плюс (N − 1) × межкарточная пауза и подготовка браузера. При паузе 20 секунд и наблюдавшихся 22,33–30,69 секунды на карточку 10 похожих карточек заняли бы примерно 6,7–8,1 минуты без повторов. Это оценка, а не подтверждённая пропускная способность очереди.

**Итог: ограниченная проверка пройдена; массовый сбор не проверен.** Дополнительные потоки, процессы, компиляция и GPU не устраняют ожидание сайта и в текущей конфигурации не нужны. Маршрутизация ресурсов Playwright отключает HTTP-кэш браузера; повторное использование относится к JSON с данными, а не к сетевому кэшу изображений и сценариев.

Перед увеличением очереди следует проверить небольшой пакет на целевом компьютере: время, потребление памяти всей группой процессов Chromium, коды ответов и полноту результатов. Изменение селекторов, версии браузера, формата страницы или масштаба требует повторной проверки затронутых этапов. При сохраняющемся 429, CAPTCHA или отказе в доступе очередь останавливается с сохранением прогресса.

2. Python читает конфиг или файл до 10 МБ, проверяет все контуры, координаты и топологию. FeatureCollection объединяется геометрически; отдельные контуры и отверстия сохраняются. Геометрия и рамка используются поиском, фильтром и ключом кэша.
3. Shapely подготавливает геометрию один раз перед обходом. Для каждого кандидата сначала проверяются координаты и рамка, затем точный полигон, затем рубрики. Границы контуров включаются, внутренние части отверстий исключаются. Новые источники координат не добавлялись.
4. Поисковые снимки и объединённый результат сохраняют `geometry`. Совместимость кэша включает полный контур; одинаковая рамка не означает одинаковую область. Отзывы продолжают использовать прежнюю последовательную очередь и её ограничения доступа.

Дополнительный параллелизм и GPU не применяются. Геометрия не создаётся заново для каждой организации; координаты не округляются и не сокращаются. Shapely выбран для готовой проверки самопересечений и отверстий, вместо собственной реализации сложной топологии. NumPy устанавливается как зависимость Shapely; отдельной вычислительной ветви для него нет.
